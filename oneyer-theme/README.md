# Oneyer StuFlow · WordPress 经典主题

基于 StuFlow 静态原型（`oneyer/` 目录 8 个 HTML 单页）实现的现代技术博客 WordPress 经典主题。
无构建工具、无付费插件依赖，全部功能基于 WordPress 核心。

![主题截图](screenshot.png)

## 环境要求

| 项 | 要求 |
|---|---|
| WordPress | ≥ 6.0（已在 WP 7.1.3 / PHP 8.3.35 实测） |
| PHP | ≥ 7.4 |
| 付费插件 | 不需要 |
| 主题大小 | < 300 KB（不含截图） |

## 安装

1. 后台「外观 → 主题 → 安装主题 → 上传主题」，选择 `oneyer-stuflow.zip`。
2. 启用「Oneyer StuFlow」。
3. （推荐）「设置 → 固定链接」选择除「朴素」外的任意结构并保存。

回滚：切回原主题即可；主题不写库表、不删内容，友链数据保留在 `oy_friend_link` 文章类型中。

## 必做配置

### 1. 后台顶级菜单「ONEYER」（推荐主入口）

启用主题后，后台左侧栏出现 **ONEYER** 菜单（位于「外观」上方），进入即为主题设置页：
6 个标签页（基本 / 首页 / 文章页 / 关于页 / 订阅与友链 / 高级）覆盖全部配置：

- 基本：**站点 Logo**（填单个字符显示渐变方块；填图片链接显示圆角图片；留空回退「外观→自定义Logo」或站点名首字。导航/抽屉/页脚/关于页站长头像/友链页本站信息卡五处同步）、建站日期、备案号、页脚附言
- 首页：问候语 / 大标题 / 副标题 / 统计卡开关 / 分类筛选条开关 / 每页篇数 / 加载更多条数 / 热门榜·标签云·友链卡数量
- 文章页：悬浮目录开关、阅读时长开关、相关文章条数（0=关闭）、分享按钮开关
- 关于页：站长简介 / 标签 / 技能栈 / 本站构成
- 订阅与友链：公众号 / Telegram / RSS 卡开关 / 头像建议文案
- 高级：自定义 CSS（自动消毒防逃逸）、时间线归档最大拉取数

数据与「外观 → 自定义 → Oneyer 站点信息」**同存储**（theme_mods），两个入口可同时使用、互相同步。

### 2. 外观 → 自定义 →「Oneyer 站点信息」（实时预览入口）

| 设置 | 说明 | 留空行为 |
|---|---|---|
| 建站日期 | YYYY-MM-DD，用于「天运维」统计 | Hero 第 4 格改显示标签数 |
| ICP / 公安备案号 | 页脚备案行 | 整行不输出 |
| 首页大标题 | 支持 `<span class="hl">`、`<br>` | 使用默认文案 |
| 首页副标题 | | 使用站点副标题 |
| 关于页 · 站长简介 / 标签 | 关于页站长卡 | 对应行隐藏 |
| 关于页 · 技能栈 | 每行 `名称\|描述\|百分比\|#色1,#色2` | 整个区块隐藏 |
| 关于页 · 本站构成 | 每行 `名称\|内容\|徽章` | 整个区块隐藏 |
| 微信公众号 / Telegram 链接 | 订阅卡与页脚 | 对应卡片隐藏 |
| 友链页 · 头像建议文案 | 本站信息卡 | 默认生成 |

### 2. 外观 → 菜单

- **主导航（桌面）**：未配置时自动回退为「顶层分类 + 关于页」，无告警。
- 主导航二级项：给菜单项添加子项即成双列下拉；子项的「描述」字段（菜单选项中勾选显示）会显示为副标题。
- **移动端抽屉菜单**：未配置时复用主导航；两者都未配置时回退为「分类 + 计数」。
- **页脚 · 栏目列 / 站点列**：未配置时分别回退为分类列表 / 自动发现的三张模板页面。

### 3. 设置 → 阅读

- 「最新文章」（默认）：首页即博客卡片流。
- 「静态页面」：同样呈现博客卡片流（`front-page.php` 内置显式查询 + `/page/N/` 分页），页面正文不会展示在首页。
- 评论免登录：「设置 → 讨论」勾选「发表评论无需注册」；首次评论进入审核由「评论必须经人工审核」控制。

### 4. 创建三个页面模板页（可选但推荐）

后台「页面 → 新建页面 → 页面属性 → 模板」：

| 模板 | 建议标题 | 页面正文用途 |
|---|---|---|
| 归档时间线（Oneyer） | 文章归档 | 不需要正文 |
| 关于页（Oneyer） | 关于本站 | 显示在统计与里程碑之间的可编辑区 |
| 友情链接（Oneyer） | 友情链接 | 申请条件列表（留空用默认文案） |

页脚「站点」列与 404 页「翻翻归档」会自动发现这些页面并生成入口。

### 5. 友情链接数据

后台「友情链接 → 添加友链」：

- 标题 = 站点名称；「站点地址 / 简介 / 分组 / 头像字符 / 头像底色 / 徽章文字 / 状态」在友链编辑页的「友链信息」盒子中维护。
- 状态选「已失联」的条目进入失联区（不可点击）。
- 首页混排区自动取最新 4 条正常友链。
- 数据存储于 `oy_friend_link` 文章类型，主题停用不丢数据，可整体迁移为独立插件。

├── front-page.php · home.php  # 模板层级入口（复用 index.php）
├── single.php · page.php · category.php · archive.php · search.php · 404.php
├── page-templates/            # 归档时间线 / 关于 / 友链
├── template-parts/            # post-card / section-heading / empty-state / related-posts

## 正文内容样式（Markdown → 前端）

正文排版规格见仓库内《内容样式映射方案.md》，要点：

- **提示框**：在引用块首行写 `[!TIP] 标题`、`[!WARN] 标题`、`[!CAUTION] 标题`
  （与 GitHub Alerts 对齐），主题自动转为彩色提示框；也可直接手写
  `<div class="note note-tip"><span class="ic">i</span><div>…</div></div>`。
- **代码块**：编辑器使用 `语言` 标记（如 ```ts）即得深色窗口块 + 语言徽标 + copy 按钮；
  首行 `// file: 路径` 会提取为标题栏文件名。已兼容 Prism 等高亮插件的 token class。
- **表格 / 代码块包裹**：由过滤器自动补全（幂等，重复渲染不双重包裹）。
- **标题目录**：h2/h3 自动注入锚点并生成悬浮目录（h2 编号 01/02…，h3 为子级）。
- **编辑器同步**：`python docs/build-editor-css.py` 从 main.css 同步区重新生成
  editor.css（Gutenberg 与经典编辑器双作用域），保证后台所见即所得。

## 设计与数据说明

- 原型中的假数据（统计数字、演示卡片、假友链、假备案号等）全部替换为 WordPress 真实数据；
  卡片悬浮徽章显示真实评论数（无可靠阅读量数据源，不伪造）。
- 卡片无特色图时保留原型的「渐变色板 + 字符」兜底（按分类 slug 稳定取色），这是本主题的视觉识别特征。
- 字体：中文使用系统字体栈；`assets/fonts/fonts.css` 存在时自动加载本地化的 Outfit / JetBrains Mono，
  不请求任何远程字体域名。
- 「加载更多」为 AJAX 增强层；禁用 JS 时自动回退为常规分页，SEO 不受影响。

## 已知限制

1. 日期归档在 `/%post_id%/` 这类纯数字固定链接下被 WordPress 核心禁用（主题 `archive.php` 已支持，
   换用含 `%year%/%monthnum%` 的结构即可用）。
2. 「总阅读量」没有可靠数据源，相关位置以评论数替代。
3. 友链 CPT 注册在主题内；若站点未来深度使用友链，建议迁移为独立插件（数据不受影响）。
