# ONEYER · 部署文档

## 一、安装前准备

1. **备份**：备份网站文件与数据库（或使用主机商快照）。本主题不修改数据表、不改固定链接、不删内容，但备份是任何主题切换的标准前置。
2. 确认环境：WordPress ≥ 6.0，PHP ≥ 7.4。
3. 优先在测试环境（ staging / 本地）安装验证，再上生产。

## 二、安装

1. WordPress 后台 →「外观 → 主题 → 安装主题 → 上传主题」→ 选择 `oneyer.zip` → 安装。
2. 启用「ONEYER」。
3. 前台检查：首页、任意文章、任意分类、搜索、404。

> 命令行方式（可选）：
> ```bash
> wp theme install oneyer.zip --activate
> ```

## 三、安装后配置清单（按顺序）

1. **设置 → 固定链接**：选择非「朴素」结构并保存一次（仅在 URL 路由异常时才需要重复此步，不是每次部署必做）。
2. **设置 → 讨论**：如需免登录评论，勾选「发表评论无需注册」；按需勾选「评论必须经人工审核」。
3. **外观 → 自定义 → Oneyer 站点信息**：填建站日期、备案号（如有）、首页文案、关于页与友链页配置（全部可留空，留空项自动隐藏，见 README 对照表）。
4. **外观 → 菜单**：创建主导航（可含二级子菜单，子项「描述」字段会显示为副标题）并绑定「主导航（桌面）」；需要时绑定抽屉与页脚菜单位。
5. **页面模板建页**（3 个可选页面）：
   - 新建「文章归档」→ 模板选「归档时间线（Oneyer）」；
   - 新建「关于本站」→ 模板选「关于页（Oneyer）」，正文写可编辑介绍；
   - 新建「友情链接」→ 模板选「友情链接（Oneyer）」，正文写申请条件（可留空用默认）。
   页脚与 404 页会自动发现这些页面生成入口。
6. **友情链接 → 添加友链**：逐条录入（名称 / 地址 / 简介 / 分组 / 头像 / 徽章 / 状态）。
7. **图片建议**：文章特色图 ≥ 640×380（16:9.5），主题自动裁切；旧文章无特色图时显示渐变+字符兜底，无需补图。
8. 清理缓存插件缓存（如有），确认 CSS/JS 为最新版本（主题以文件修改时间做版本号，更新主题后自动失效缓存）。

## 四、生产切换与回滚

### 切换
1. 低峰期执行；切换后立即走查：首页 → 文章 → 分类 → 搜索 → 404 → 评论 → 移动端菜单。
2. 确认 SEO 插件（Yoast/Rank Math 等）标题正常：本主题使用核心 `title-tag`，不与 SEO 插件冲突；主题不输出 canonical/OG。

### 回滚
1. 外观 → 主题 → 启用原主题，完成。文章/分类/评论/页面/友链数据全部保留。
2. 清理缓存插件缓存。
3. 如需彻底移除：外观 → 主题 → 删除 ONEYER。友链数据（`oy_friend_link` 文章类型）仍保留在数据库中，重新启用主题即恢复显示；如需彻底清除，用 `wp post list --post_type=oy_friend_link` + `wp post delete` 处理。

## 五、主题更新

用新 ZIP 覆盖上传即可（后台「主题 → 添加 → 上传 → 替换当前已上传版本」）。
自定义全部存于 theme_mod 与文章元数据，不随主题文件丢失。

## 六、常见问题

| 现象 | 原因与处理 |
|---|---|
| 日期归档 404 | `/%post_id%/` 等纯数字固定链接下 WordPress 核心禁用日期归档；换含 `%year%/%monthnum%` 的结构 |
| 菜单不显示 | 未绑定菜单位时的回退只显示分类；到「外观 → 菜单」绑定 |
| 子菜单不出现 | 二级项必须挂在某个一级项下（菜单编辑器拖拽层级） |
| 「天运维」不显示 | 未填建站日期，属预期（Hero 第 4 格自动显示标签数） |
| 首页想显示静态页内容 | 本主题首页固定为卡片流布局（对应原型）；静态页内容可放到「关于页」等模板页 |
